🔎 TruthLens
📌 Overview

TruthLens is an AI-powered web application that analyzes text-based information and evaluates its credibility.
It helps users determine whether a piece of content is credible, misleading, or questionable by analyzing linguistic patterns and contextual signals.

The goal of TruthLens is to combat misinformation and fake news by providing users with quick and reliable credibility insights.

🚨 Problem It Solves

In today's digital world, misinformation spreads rapidly through social media, blogs, and online platforms.
Many users find it difficult to verify whether the information they read is authentic or not.

TruthLens solves this problem by:

⚡ Providing instant credibility analysis

🧠 Helping users make informed decisions

🌐 Promoting responsible information consumption

✨ Key Features
🔍 Text Credibility Analyzer

Users can input any piece of text (news, statements, or social media posts) and the system analyzes it for credibility.

🤖 AI-Based Verdict System

The platform classifies content into categories such as:

✅ Credible

⚠️ Questionable

❌ Misleading

🧾 Explanation-Based Output

TruthLens not only provides a verdict but also explains why the content was classified that way.

🎨 Interactive UI

A clean and responsive interface allows users to quickly paste content and view results.

⚡ Real-Time Analysis

The system processes the input instantly and displays results without delay.

⚙️ How It Works

1️⃣ User enters a piece of text.
2️⃣ The text is sent to the backend API.
3️⃣ The AI/NLP system analyzes:

language patterns

tone and claims

possible misinformation signals

4️⃣ The system generates a credibility verdict.
5️⃣ The result and explanation are displayed to the user.
